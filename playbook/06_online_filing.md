# 06 在线递交 Form I-140：操作流程与坑

本指南描述通过 USCIS 在线账户以"上传已完成 PDF"（Upload Completed PDF Online）方式递交 NIW self-petition 的流程。门户界面、分类名称、上传限制、费用都会变：凡标注 **re-verify on filing day** 的内容，都只是需要核对的项目清单，不是固定答案，必须在递交当天以官方页面和实时界面为准重新核对，并在 `case-template/workproduct/09_Forms_and_Assembly_Checklist.md` 的 Filing-Day Verification Record 中记录。

## 一、递交前一周确认的官方页面

| 项目 | 官方页面 | verified on |
| --- | --- | --- |
| I-140 是否仍在 PDF 上传列表 | uscis.gov/file-online/forms-available-to-file-online | {{DATE}} |
| I-140 版本、在线入口、self-petitioner 填表提示 | uscis.gov/i-140 | {{DATE}} |
| NIW 初始证据要求（ETA-9089 文件） | I-140 initial-evidence checklist（由 uscis.gov/i-140 链接） | {{DATE}} |
| 费用（I-140、Asylum Program Fee、I-907） | uscis.gov/g-1055；uscis.gov/feecalculator | {{DATE}} |
| I-907 资格、时限、能否并行在线递交 | uscis.gov/i-907 | {{DATE}} |
| ETA-9089 Appendix A、Final Determination 当前版本 | DOL 表格页（dol.gov/agencies/eta/foreign-labor/forms） | {{DATE}} |
| 签名规则 | Form I-140 instructions；Policy Manual Vol. 1, Part B, Ch. 2 | {{DATE}} |

**停止规则**：I-140 不在 PDF 上传列表、账户里没有 NIW self-petition 路径、页面显示的费用与你按 G-1055 计算的不一致、或必需文件有变化——当天不要递交，先更新所有控制文件。

## 二、准备好的文件

| 文件 | 要求 |
| --- | --- |
| Form I-140 | 当天版本；按表格页说明选择填写工具（USCIS 部分表格是只能用 Adobe Acrobat/Reader 打开的动态表单，打不开时先查表格页说明）；打印全部页 → **手写墨水签名和日期** → 整份扫描为一个 PDF；保留原件 |
| ETA-9089 Appendix A | 全部页；内容与 I-140、CV、B/C 系列展品一致 |
| ETA-9089 Final Determination | 不经 DOL 认证；按决定的分区手写签名；扫描；保留原件 |
| Form I-907（可选） | 手写签名扫描；并行递交时"相关收据号"一栏留空 |
| Petition letter、H-1、H-2 | 从冻结的最终版打印、整份签字扫描 |
| 展品 | 每个展品一个 PDF；外文展品 = 原件 + 译文 + 译者证明 |

签名坑：打字签名、印章、电子签名工具、粘贴签名图片都不被接受，即使是在线 PDF 上传方式。门户里的 attestation（声明勾选）**不能替代** PDF 上的手写签名。

ETA-9089 坑：

- 8 CFR 204.5(k)(4)(ii) 仍写着旧的 ETA-750B；USCIS 已通过 2025 年 1 月 14 日 Federal Register 公告改为 ETA-9089 Appendix A + Final Determination。以当前 USCIS 说明为准，不要照旧教程。
- 以当前 I-140 表格说明和 initial-evidence checklist 列出的 ETA-9089 文件为准（re-verify on filing day）。如果不同 USCIS 页面对所需 ETA-9089 文件的描述互相冲突，记录冲突（页面、原文、日期），并在递交前解决——必要时请律师确认。
- Final Determination 的 Section A 是政府专用，不要编造 DOL 案号、日期或签名。checklist 要求 employer/petitioner 和 beneficiary/self-petitioner 签名；自主申请人同时是两者。若旧教程（例如"只签 Section B"）与当前 checklist 措辞冲突，以当前 checklist 为准。

## 三、I-140 关键字段

| 部分 | 要点 |
| --- | --- |
| Part 1 | 查看 uscis.gov/i-140 和表格说明中是否有针对 self-petitioner 的填答提示（例如与 Asylum Program Fee 相关的雇主类型、员工人数问题），按当天页面作答并记录（re-verify on filing day） |
| Part 2 | 选 NIW 项（advanced degree 或 exceptional ability），依据写 advanced degree |
| Part 3 | 身份、入境、I-94 信息逐项对照原件；递交当周重新下载最新 I-94 |
| Part 4 | 调整身份或领馆办理二选一 |
| Part 5 | 当前职业（可与 Part 6 不同）；年收入只填在表上，不上传工资文件 |
| Part 6 | 职位名称、SOC code、非技术描述必须与 endeavor 一致；描述框只有几行：框内写短版并注明见 Part 11，全句写进 Part 11 |
| Part 6 其余 | full-time、permanent、new position、wage、worksite：NIW 免除 job offer，不要照抄当前雇主的薪资和工作地点，也不要编造雇主；逐项决定并在 Part 11 解释 Part 5 与 Part 6 的区别 |
| Part 7 | 所有配偶和子女，即使不随行 |
| Part 11 | 每条续写注明 page / part / item |

门户里重复出现的就业或工作地点问题，答案与 PDF 保持一致。

## 四、门户操作步骤（re-verify on filing day）

1. 登录自己的 USCIS 在线账户（my.uscis.gov）。
2. 选择 File a Form → Form I-140 → 上传已完成 PDF → NIW self-petition。
3. 回答门户筛选问题，与 PDF 一致。
4. "Upload Form I-140"：上传手写签名的 I-140 扫描件。
5. 若门户提供并行 I-907 选项且你已决定使用："Upload Concurrent PDF(s)" 上传 I-907 扫描件。
6. 按分类上传 ETA-9089 文件和证据。
7. 审阅汇总页：逐个文件对照上传清单（manifest）核对文件名、分类、页数；抽查预览。
8. 保存汇总页（PDF 或截图），再付款。
9. 完成 attestation → 跳转 Pay.gov 付款。
10. 保存确认页、Pay.gov 收据、案件卡片。

门户分类示例（名称和数量以实时界面为准，递交当天逐项对照）：

| 门户分类 | 放什么 |
| --- | --- |
| Upload Form I-140 | I-140 签字扫描件 |
| Upload Concurrent PDF(s) | I-907 签字扫描件（如使用） |
| (I-140) Form ETA-9089 | 已签名 Final Determination（以及你判断需要的主表） |
| (I-140) Form ETA Appendix A | Appendix A |
| (I-140) Evidence Supporting National Interest Waiver | Petition letter、展品索引、D–J 系列、H 系列 |
| (I-140) An official academic record | B 系列 |
| (I-140) Additional Evidence | A 系列、C 系列 |
| Proof of exceptional abilities；Form ETA-750/750B | advanced degree 路线留空 |

上传限制（re-verify on filing day）：

| 限制 | 做法 |
| --- | --- |
| 格式 | 在实时上传界面确认接受的文件类型；本套件输出 PDF |
| 单文件大小 | 有单文件大小上限，以实时上传界面为准；本套件默认把每个文件构建在 11.5 MB 以下（`case.json` 的 `upload_limit_bytes`），界面上限更低时调小该值后重建 |
| 每次上传动作 | 可能限制每批文件数，需要分批；以实时界面为准 |
| 加密 PDF | 不要上传加密或带密码的 PDF |

上传坑：

- 不要上传合并后的整本审阅 binder；按展品分别上传，文件名以展品 ID 开头，便于 officer 按顺序阅读。
- 超大展品拆成 Part 1 / Part 2，不要压缩到看不清。
- 含交互表单字段（widget）的页面（可填写的证书、PDF 编辑器签的译者证明）在去除字段或扁平化时可能丢失可见内容；先栅格化这些页，再人工查看每一页。
- 先按分类和界面的每批文件数准备好分批清单，递交当天逐批勾选。

## 五、付款（re-verify on filing day）

- 只通过 USCIS 流程内跳转的 Pay.gov 付款；不要自己在 Pay.gov 搜索 I-140 付款表单。
- 付款页显示的总额必须等于你按当天 G-1055 计算的总额；不一致就停止核对。
- 可用的付款方式（如银行卡、美国支票账户扣款）以当天付款页为准。
- 金额较大（尤其含 premium processing）时，提前通知发卡行，确认单日限额和风控不会拒付。
- 付款凭证存入私有记录，卡号、账号不进入任何证据文件。

## 六、premium processing 的递交方式

I-140 与 I-907 能否在线并行递交，以 uscis.gov/i-907、uscis.gov/i-140 和当前表格说明为准（re-verify on filing day）；如果官方页面之间、或官方页面与在线账户流程之间互相冲突，记录冲突并在递交前解决。做法：

1. 递交当天核对官方页面和登录后的实时流程，截图保存所见文字；
2. 若流程提供并行 I-907，则使用并确认付款页同时显示两项费用；
3. 若不提供，先递交 I-140，拿到收据号后在线单独提交 I-907。

premium processing 保证在规定时限内作出"行动"（批准、RFE、NOID 或拒绝），不保证批准；RFE 会暂停计时。时限见 uscis.gov/i-907。

## 七、递交后

| 事项 | 做法 |
| --- | --- |
| 记录提交时间 | 精确到分钟并注明时区 |
| priority date | 依据 8 CFR 204.5(d) 为 properly filed 之日；USCIS 按自己的服务器时间记录，跨时区或深夜递交时，记录的日期可能与本地日期不同，不同页面显示也可能不一致。以邮寄的 I-797C 为准 |
| 被拒收（rejection） | 被拒收的申请没有收据日期；关注账户通知 |
| 保存 | 确认页、Pay.gov 收据、案件卡片、premium 收据邮件、I-797C、实际上传的全部文件、manifest 和哈希清单，放在一起 |
| 冻结 | `make freeze CASE=cases/<id> LABEL=filed-YYYY-MM-DD`，并打 Git tag；已递交的草稿和证据不再修改 |
| 状态时间线 | 写入收据号、收据日期、premium 截止日（按工作日计算） |
| 地址变更 | 搬家后按规定时间内在线更新地址（uscis.gov/ar-11） |
| RFE | 收到当天日历化期限；期限以通知为准，可能短于 12 周上限（8 CFR 103.2(b)(8)(iv)，核对现行条文）；所有材料一次性回复（8 CFR 103.2(b)(11)）；原通知放在最上面；先在账户确认能否在线上传回复，否则按通知上的地址邮寄；新证据使用新的展品系列 |
| 身份 | I-140 递交或获批不提供身份、工作许可或出入境保障；继续独立维持非移民身份 |
